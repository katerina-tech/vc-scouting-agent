## 🎯 The Problem

Startup scouting is fragmented, time-consuming, and difficult
to reproduce. Analysts need to review information from multiple
sources, verify claims, compare companies, and document decisions.

## ✨ The Solution

VC Scouting Agent streamlines startup research while keeping
investment decisions transparent and human-controlled.

| Feature | What it does |
|---|---|
| 🔎 Discovery | Ingests startup information |
| 🧹 Normalization | Cleans and deduplicates company data |
| ✅ Eligibility | Applies deterministic investment criteria |
| 📊 Scoring | Ranks startups using a weighted framework |
| 🧠 AI Analysis | Generates evidence-grounded research |
| 👤 Human Review | Supports analyst overrides and shortlisting |

## 🏗️ Architecture

```text
Startup Data

     |

     |

     |
     v

```

## 🛡️ Reliability & Safety

- Deterministic investment eligibility rules
- Evidence-backed research and traceability
- Structured LLM output validation
- Human-in-the-loop decisions
- Automated regression testing
- Fallback behavior when LLM services are unavailable
